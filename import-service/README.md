# Import Service

Микросервис импорта данных.

## Функциональность

- Загрузка CSV-файлов через multipart/form-data
- Стратегии импорта: товары, цены, остатки
- Маппинг колонок CSV на поля модели (гибкая конфигурация)
- Построчная валидация с накоплением ошибок (EventNTree)
- State machine статусов задачи импорта
- Асинхронная обработка файлов через RabbitMQ
- Реестр стратегий импорта (`ImportStrategyRegistry`)
- Шаблоны ошибок (`ErrorTemplate`) для типовых проблем
- Файловое хранилище: локальное / S3

## API

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/imports/upload` | Загрузить CSV-файл для импорта |
| `GET` | `/imports` | Список задач импорта продавца |
| `GET` | `/imports/{id}` | Статус задачи импорта |
| `GET` | `/imports/{id}/errors` | Ошибки импорта |
| `GET` | `/error-templates` | Список шаблонов ошибок |

## Типы импорта

| Тип | Стратегия | Описание |
|-----|----------|----------|
| `products` | `ProductsImport` | Создание/обновление товаров |
| `prices` | `PricesImport` | Массовое обновление цен |
| `inventory` | `InventoryImport` | Импорт остатков на склады |

## Статусы задачи импорта

```
pending → processing → completed
                    ↘ failed
```

Ошибки валидации накапливаются в `error_description` (JSONB).

## Хранилище файлов

| Стратегия | Описание |
|-----------|----------|
| `local` | Файлы в `/tmp/imports` (по умолчанию) |
| `s3` | S3-совместимое хранилище (MinIO) |

## Порты
